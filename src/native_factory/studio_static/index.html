Important boundaries

  • A web commit can automatically reach internal testing.
  • Apple and Google production updates can still require review.
  • Never commit signing keys or store service-account JSON.
  • Each installed app needs a permanent unique identifier.
  • Customer, Driver and Kitchen apps are separate binaries.
  • Test camera, push, uploads and offline behaviour on real devices.
